# LevTrack

기초지수(QQQ, SOXX, SPY)로 국면과 손절·익절을 계산하고, 레버리지 ETF(TQQQ/SQQQ, SOXL/SOXS, UPRO/SPXU)의 진입가·수량·주문가로 바꿔 주는 개인용 기술적 분석 웹앱입니다. 기획 내용은 [PLAN.md](PLAN.md)에 있습니다.

## 기본 전략: 추세 롱숏 (3배 롱 / 3배 숏)

기초지수 **일봉 종가**로 판단하고 **다음 거래일**에 실행합니다 (한국 아침 확인 → 밤 미국장 개장 직후 주문).

| 상태 | 진입 | 청산 | 종목 · 비중 |
|---|---|---|---|
| 📈 추세 롱 | 종가 > 200일선 × 1.03 | 종가 < 200일선 × 0.97 | 3배 롱, 변동성 맞춤 |
| 📉 반등 숏 | 200일선 아래 · 50일선 < 200일선 · RSI(2) > 90 | RSI(2) < 30 / 5거래일 / 하락 조건 해제 | 3배 숏, 변동성 맞춤 |
| 🔁 과매도 롱 | 200일선 아래 · RSI(2) < 10 | RSI(2) > 70 / 5거래일 | 3배 롱, 절반 |
| 💤 현금 | 그 외 | | |

비중 = min(100%, 목표 변동성 40% ÷ (3 × 최근 20일 변동성)), 목표와 10%p 이상 차이 날 때만 조정.

**실제 데이터 백테스트** (합성 3배 ETF, 차입비용 = 2×(국채금리+0.5%), 현금은 국채금리, 편도 0.1% 비용, 다음 날 시가 체결, 세금 제외)

| 기초 (기간) | 추세 롱숏 CAGR / MDD / 샤프 | 기초 1배 보유 CAGR / MDD / 샤프 |
|---|---|---|
| QQQ (1999~) | 15.3% / −58% / 0.58 | 7.6% / −83% / 0.41 |
| SOXX (2001~) | 15.2% / −55% / 0.57 | 12.9% / −67% / 0.53 |
| SPY (1993~) | 15.6% / −44% / 0.61 | 8.8% / −57% / 0.54 |

### ⚠️ 과최적화 검증 결과 — 설계에 쓰지 않은 데이터에서는 실패

위 규칙은 QQQ·SOXX·SPY 1993~2026 데이터를 보고 골랐습니다. **규칙을 그대로** 처음 보는 기간·시장에 적용하면:

| 처음 보는 데이터 | 추세 롱숏 샤프 | 추세 롱만 샤프 | 1배 보유 샤프 |
|---|---|---|---|
| S&P500 1962~1992 | 0.03 | 0.39 | 0.49 |
| 나스닥종합 1972~1998 | 0.21 | 0.84 | 0.85 |
| 다우 1993~ | 0.38 | 0.38 | 0.56 |
| 러셀2000 1988~ | 0.12 | 0.24 | 0.46 |
| 닛케이 1966~ | 0.28 | 0.34 | 0.42 |
| DAX 1989~ | 0.43 | 0.49 | 0.47 |
| FTSE 1985~ | 0.19 | 0.22 | 0.40 |
| 항셍 1988~ | 0.21 | 0.41 | 0.38 |

- **반등 숏 · 과매도 롱(RSI(2) 단기 역추세)이 과최적의 주범**: 설계 데이터에선 소폭 도움, 처음 보는 8개 데이터 **모두에서 성과를 깎음**.
- 3배 추세 롱만도 1배 보유보다 위험 대비 수익이 일관되게 낫지 않음 (나스닥은 비슷한 샤프에 더 높은 수익, 다우·러셀·닛케이·FTSE 는 열위).
- 결론: 현재 규칙의 숏 부분은 **검증된 우위가 없습니다.** 실제 돈을 넣기 전에 이 점을 감안하세요.

### 숏 규칙 재탐색 (학습/검증 분리)

- **방법**: 문헌 근거가 있는 숏 규칙 6개를 미리 정하고(12개월 시계열 모멘텀[Moskowitz·Ooi·Pedersen 2012], 월말 판단, 1·3·6·12개월 앙상블,
  200일선 ±3%, 모멘텀+200일선, 10개월선[Faber]), **1998년 이전 데이터(S&P500·나스닥·닛케이·FTSE)로만 고른 뒤**
  **1999년 이후 9개 시장**(QQQ·SPY·SOXX·다우·러셀·DAX·닛케이·FTSE·항셍)에서 한 번만 검증.
- **결과**: 학습용에서도 평균 개선 없음, 검증용 9개 시장 **모두에서 성과 악화**(샤프 평균 −0.09, MDD −18%p). 3배 인버스로 추세형 숏을 하면 우위가 없음.
- 현재의 **RSI(2) 역추세(반등 숏·과매도 롱)** 는 1999년 이후엔 9개 중 7개 시장에서 개선(설계에 안 쓴 다우·러셀·닛케이·FTSE 포함), 1998년 이전엔 모두 악화 → **시기 의존적**.
- 그래서 **역추세 자동 점검(게이트)** 을 기본으로 켬: 역추세 다리를 '했다면'의 최근 3년 성과가 마이너스면 그 신호를 쉬고 현금.
  12개 시장·기간 평균 샤프: 추세 롱만 0.39 · 롱숏(항상) 0.31 · **롱숏(게이트) 0.37** — 최악의 경우(1972~98 나스닥 −0.64)를 −0.03 으로 줄이지만,
  평균적으로는 여전히 추세 롱만보다 약간 낮습니다. ⚙️ 설정에서 역추세를 끄거나(추세 롱만) 게이트를 끌 수 있습니다.
- 이전의 **스윙 규칙**은 설계 데이터에서도 연 0~1% 로 우위가 없어 "실험용"으로 남겨 두었습니다 (⚙️ 설정 → 전략).
- **기술 지표 추가 실험**: MACD · ADX · 골든크로스 · RSI(14) · OBV · VIX · 상대강도 · 모멘텀 · 볼린저 등 19개를 하나씩·합의 점수로 넣어도 일관된 개선이 없어 규칙에 넣지 않았습니다. 플래너의 **🔬 참고 지표** 패널에서 볼 수 있습니다.

## 실행

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app/streamlit_app.py # 브라우저에서 http://localhost:8501
```

## 매매일지 저장 (GitHub, 무료)

Streamlit Cloud 는 서버 파일이 재시작 때 지워지므로, 일지는 이 저장소의 **`journal-data` 브랜치**에 저장하는 것을 권장합니다
(앱이 배포된 브랜치와 달라서 저장해도 앱이 재배포되지 않습니다).

1. GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → *Generate new token*
   - Repository access: **Only select repositories** → `ysh030812-collab/stock`
   - Permissions → Repository permissions → **Contents: Read and write**
2. share.streamlit.io → 앱 ⋮ → **Settings → Secrets** 에 붙여넣고 저장
   ```toml
   [journal]
   github_token = "github_pat_여기에_토큰"
   repo = "ysh030812-collab/stock"
   branch = "journal-data"
   ```
3. 앱의 📒 일지 화면 상단이 "저장 위치: GitHub …" 로 바뀌면 완료. 첫 저장 때 `journal-data` 브랜치가 자동으로 만들어집니다.

설정 전에는 서버 파일에 저장되니, 일지 → **백업**에서 JSON 을 받아 두세요 (같은 화면에서 다시 불러올 수 있음).
내 PC 에서 실행할 때는 `data/journal.json` 에 저장됩니다.

| 매매일지 | 진입·분할 청산 기록, 보유 포지션 평가손익·R, 통계(승률·평균 R·손익비), 익절 분할 비교, 조건별 성과, 연도별 손익·양도세 추정, 백업 |

## 반영된 기술적 분석

| 구분 | 내용 | 사용처 |
|---|---|---|
| 추세 | SMA50/200, SMA50 기울기, EMA20/50 | 방향 점수 (일봉) |
| 모멘텀 | RSI(14), MACD(12,26,9), ROC(20) | 방향 점수 |
| 구조 | 52주 범위 위치, 돈치안(20) | 방향 점수, 돌파 판단 |
| 거래량 | OBV, 상승봉 거래량 비중, 거래량 비율 | 방향 점수, 돌파 확인 |
| 상대강도 | QQQ/SPY, SOXX/QQQ | 방향 점수 |
| 다이버전스 | RSI · MACD 히스토그램 정규 다이버전스 | 점수 보정, 시간봉 트리거 |
| 캔들 패턴 | 장악형, 망치형/유성형, 샛별형/석별형, 도지, 인사이드바 | 시간봉 진입 트리거 |
| 피보나치 · 매물대 · 스윙 | 되돌림/확장, POC/VAH/VAL/HVN, 피벗 고저점 | 지지대 손절, 피보나치/저항대 익절 |
| 변동성 | ATR, 실현변동성 백분위, VIX/VXN | 손절폭, 비중 감액 |
| 다중 시간대 | 일봉 국면 + 시간봉 진입 타이밍 | 대시보드 · 플래너 |

자세한 규칙은 [PLAN.md](PLAN.md) 4.3 ~ 4.4를 참고하세요.
